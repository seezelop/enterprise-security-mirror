# Enterprise Security Mirror (ESM)

Defensive cybersecurity lab implementing a fictional enterprise network with HQ, three branches, OSPF, VLAN segmentation, nftables firewalls, a DMZ, and automated checks.

**Implemented:** ESC-001, Web Application Security. FastAPI HTTPS portal, controlled BOLA reproduction (performed locally during development), audit-log detection, remediation and an audit-telemetry blind-spot exercise.

**Planned, not deployed:** ESC-002 Identity & Privilege Abuse; ESC-003 Lateral Movement & Resilience. No Active Directory, production database, SIEM or separate IDS is deployed in ESC-001.

## Architecture

- 24 Containerlab nodes: 18 Linux containers and six Open vSwitch bridges.
- 23 topology links.
- A fictional external client (`internet01`) connects through `isp01`, `edge-r01`, `firewall01` and the dedicated DMZ to `web01`.
- The HTTPS portal is published through DNAT: `203.0.113.2:443` to `10.70.50.10:443` (documentation-only addresses).
- A separate corporate core connects HQ user, server, admin and management segments plus three branches via OSPF.
- BOLA audit logs are generated by FastAPI. `detect_bola.py` is an **on-demand log analyzer**, not an always-on SOC sensor.

## Validation

`./scripts/deploy-lab.sh` (run from `infrastructure/containerlab/`) executes the infrastructure policy suite after deployment. The local integration suite is **12 policy checks**, including three expected OSPF neighbors and the HTTPS DMZ health endpoint. Some policy checks use lightweight Netcat listeners for simulated services.

GitHub Actions (`.github/workflows/ci.yml`) runs **offline/static checks and Python tests**; a green CI run does **not** prove that Docker, OVS, OSPF or the HTTPS network path work on another machine.

## Safety and scope

Only run in an isolated, authorized Linux lab. Never publish host ports, bridge this topology to a real company network or use the demonstration credentials elsewhere. HTTPS currently uses an ephemeral, self-signed certificate. Logs and accounts are synthetic; the application is not production-ready.
